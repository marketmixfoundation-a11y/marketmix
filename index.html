How the blur happens

  1. 01

    Find the subject

    A segmentation model runs on every frame, on your device, and keeps a mask of the person.

  2. 02

    Mix sharp and soft

    The mask blends a sharp copy of the frame with a GPU-blurred copy of the background.

  3. 03

    Write it into the file

    On Android the finished frame goes straight into the video encoder — the blur is in the recording, not added later.

Install

Windows

  1. Download MarketMix-Edit-Setup-0.1.0.exe above.
  2. Run the installer and pick an install folder.
  3. If Windows SmartScreen appears, choose More info → Run anyway. The installer is not code-signed.
  4. Open MarketMix Edit from the Start menu.

Android

  1. Download MarketMix-Camera-0.1.0.apk on your phone.
  2. Open it and allow install unknown apps for the app you downloaded it with.
  3. Tap Install, then allow camera and microphone access.
  4. Press the red button to record. Clips land in Movies/MarketMix Camera.

Source
